# Zomato Data Analysis & Power BI Dashboard

## 📊 Project Overview

This project focuses on analyzing Zomato restaurant data and presenting meaningful insights through an interactive Power BI dashboard.

The dataset contains information about restaurants, locations, cuisines, ratings, costs, online ordering, table booking, and other restaurant-related attributes.

The project combines data preparation, data analysis, and visualization to understand restaurant trends and customer preferences.

## 🎯 Objectives

- Analyze restaurant data from the Zomato dataset.
- Understand restaurant distribution across different locations.
- Analyze restaurant ratings and customer votes.
- Explore cuisines and restaurant categories.
- Analyze online ordering and table booking availability.
- Understand restaurant pricing and cost-related patterns.
- Create an interactive Power BI dashboard to present the findings.

## 🔄 Data Preparation

The Zomato dataset was prepared using Power Query in Power BI.

The main data preparation steps include:

- Importing the Zomato dataset.
- Importing the country code dataset.
- Checking and correcting data types.
- Handling missing and inconsistent values.
- Cleaning the dataset.
- Transforming columns where required.
- Combining relevant datasets.
- Preparing the data for analysis and visualization.

## 📊 Power BI Dashboard

The Power BI dashboard provides an interactive way to explore the Zomato restaurant dataset.

The dashboard focuses on different aspects of restaurant data, including:

- Restaurant distribution
- Restaurant ratings
- Customer votes
- Cuisines
- Locations
- Average cost
- Online ordering
- Table booking
- Restaurant categories

Interactive filters and visualizations allow users to explore the data based on different attributes.

## 🔍 Key Analysis Areas

### Restaurant Analysis

The dashboard analyzes the distribution of restaurants across different locations and categories.

### Rating Analysis

Restaurant ratings and customer votes are analyzed to understand restaurant performance and customer response.

### Cuisine Analysis

The project explores different cuisines available in the dataset and their distribution across restaurants.

### Cost Analysis

Restaurant pricing and average cost for two people are analyzed to understand cost-related patterns.

### Location Analysis

The dashboard provides insights into restaurant distribution across different countries, cities, and locations available in the dataset.

### Online Ordering Analysis

Restaurants are analyzed based on whether online ordering facilities are available.

### Table Booking Analysis

The dashboard analyzes restaurants based on the availability of table booking facilities.

## 🚀 How to Run the Project

1. Clone this repository.
2. Open the project folder.
3. Open `zomato.pbix` using Microsoft Power BI Desktop.
4. If Power BI asks for the dataset location, select the required files from the `datasets` folder.
5. Refresh the data if required.
6. Use the available filters, slicers, charts, and visualizations to explore the dashboard.
